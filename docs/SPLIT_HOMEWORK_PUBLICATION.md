# Независимое назначение ежедневных и еженедельных заданий

Подготовлено 28 октября 2026 года в `Sashamath_bot_2_main`.

В планировщике две кнопки: «Назначить ежедневные» и «Назначить еженедельное».
Дата начала недели и аудитория общие. Отправляется только выбранный тип заданий;
после успеха очищается только его блок. Дата, аудитория и второй блок сохраняются.
Частично заполненное отправляемое задание вызывает понятную ошибку.

Новая функция `publish_homework_self` объединяет присланные слоты с существующими
активными слотами на сервере под блокировкой плана. Пустые поля не снимают задания,
включая незаполненные дни ежедневного блока. Блокировка по неделе и аудитории
защищает также первую публикацию, когда строки плана ещё нет.

Функция использует существующий `publish_weekly_plan_self`, сохраняя проверку роли
учителя, аудит, синхронизацию ученикам, защиту начатых работ и повторную отправку.
Редактор отдельных заданий и явное удаление продолжают использовать прежний
контракт полной публикации. Старый открытый планировщик нужно обновить после выпуска.

## Применение

Миграция применена 28 октября 2026 года в `sasha-math-bot-2-dev`.
После применения SQL-регрессия прошла повторно; тестовые данные полностью откатились.
Версия в истории Supabase: `20261028142152`.

1. В `sasha-math-bot-2-dev` применить полный SQL из
   `database/migrations/20261028142152_split_homework_publication.sql`.
   Он добавляет функцию и её права; существующие данные не переписывает.
2. Опубликовать `teacher.html` и `js/teacher-planning.js` вместе после миграции.
   В HTML обновлена версия JS для загрузки нового обработчика.
3. Обновить страницу учительской. Ежедневные и еженедельное можно назначать
   по очереди, с одинаковой датой начала недели и нужной аудиторией.

Миграция должна предшествовать публикации клиента: новая форма использует новый RPC.
Уже исчезнувшие до исправления задания автоматически не восстанавливаются.
